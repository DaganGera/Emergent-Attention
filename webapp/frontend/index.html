How this system works

Every image you test takes the same path: it's standardised, then reviewed in two stages — first region-by-region for local consistency, then as a whole for global context — before a decision stage produces the classification above. An explanation module then marks the region of the image that most influenced that decision (the heatmap), and a reasoning module writes the plain-language paragraph above it.
